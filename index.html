Manna Origins, contract, 2026

Prospecting pipeline

Eight stages, three Claude agents, and plain rules where rules work better.

  • Python
  • Anthropic SDK
  • Google Places
  • Apollo
  • Gmail API
  • Notion API
  • SQLite
  • YAML

The problem

Manna imports specialty coffee and sells it to cafés and roasters. Finding and contacting those buyers was all manual: searching maps, reading websites, writing emails one at a time.

What I built

A Python pipeline that finds businesses, researches each one, scores the fit, drafts a personal email, sends it, reads replies, and hands warm leads to sales in Notion.

The result

Each prospect takes about 35 seconds. The first pilot of 37 prospects surfaced 14 top-tier fits.

192prospects I checked by hand before automating anything
~35 secper prospect once the pipeline runs on its own
14 of 37top-tier fits found in the first pilot

Decisions that mattered

Claude only where judgment helps

Research, writing, and reading replies use Claude. Scoring is plain rules in a YAML file, so it's predictable, cheap, and easy to change.

One failure doesn't stop the run

Each stage handles its own errors. Failed prospects go into a retry queue with the error saved, and every run ends with a summary.

No duplicates, full trail

The database blocks repeat prospects, and every stage writes to a log, so I can trace what happened to any lead.

Built for more than one client

Each client gets its own database, settings, and logs. A learning module suggests changes, and a person approves them first.
